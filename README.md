# Entanglement generation by unequal-dimension Bell-diagonal projections and a no-go theorem for local twirling

**An audit and restoration of Phys. Rev. A 109, 012217 (2024)**

Author: Ruqing Chen (Independent Researcher, Montreal, Quebec, Canada) · ORCID [0009-0009-4622-6615](https://orcid.org/0009-0009-4622-6615)

This repository contains the manuscript, the deterministic verification script and the figure
script for an audit of Proposition 1 of

> J. Moerland, N. Wyderka, H. Kampermann, and D. Bruß,
> *Bound entangled Bell diagonal states of unequal local dimensions, and their witnesses*,
> Phys. Rev. A **109**, 012217 (2024), [doi:10.1103/PhysRevA.109.012217](https://doi.org/10.1103/PhysRevA.109.012217),
> [arXiv:2308.10607](https://arxiv.org/abs/2308.10607).

Equation numbers quoted as "MWKB (n)" refer to arXiv version v2 of that paper.

## What was audited

On C^{d_A} ⊗ C^{d_B} with d_A < d_B, the audited paper defines generalized Bell states
|φ^{αβ}⟩ = (Z_A^α ⊗ X_B^β)|φ^{00}⟩ and states (Proposition 1) that the average Φ₁ over the
d_A·d_B local unitaries T(μ,ν) = X_A^μ Z̃^ν ⊗ X_B^μ Z_B^{-ν} equals the projection Π_Bell
onto the generalized Bell basis, so that this projection is a non-entangling channel.

**Finding.** For every d_A < d_B both parts of the statement fail:

1. Φ₁ is a legitimate LOCC channel, but it is **not** the Bell projection.
2. The Bell projection Π_Bell is **entangling**: it maps a pure product state to a state
   with a non-positive partial transpose.

The bound entangled states and the entanglement witnesses constructed in Sections III–V of
the audited paper do not use Proposition 1 and remain valid.

## Main results of the manuscript

| Result | Statement |
|---|---|
| **Theorem 2** – true structure of the local average | Φ₁ = (average over powers of S = X_A ⊗ X_B) ∘ (block dephasing). Φ₁ = Π_Bell if and only if d_A = d_B. For d_A < d_B: the fidelity of Φ₁(φ^{00}) with φ^{00} is (d_A+1)(2d_A+1)/(6d_A²) < 1; the group generated by the T(μ,ν) has order lcm(d_A,d_B)·d_B·(d_B/g)^{d_A} with g = gcd(d_A,d_B); the fixed-point algebra of Φ₁ has dimension g; Φ₁ⁿ converges to a dephasing-and-shift twirl (the completely depolarizing channel for coprime dimensions). |
| **Theorem 3** – entanglement generation | For all 2 ≤ d_A < d_B, the product state ρ⋆ = \|a⟩⟨a\| ⊗ \|b⟩⟨b\| with a = b = (\|0⟩+\|1⟩)/√2 satisfies λ_min(Π_Bell(ρ⋆)^{T_A}) = **−1/(4 d_A)**, with exactly one negative eigenvalue. In 2×3 this is the eigenvalue −1/8 of a 2×2 rational block. |
| **Proposition 5 and Theorem 6** – no-go | The pinching onto an orthonormal basis is the unique positive trace-preserving map with outputs diagonal in that basis that fixes the basis projectors. Hence for d_A < d_B no LOCC, separable, PPT or separability-preserving channel Bell-diagonalizes, and every channel mapping product states to PPT states has diamond distance at least 1/(4 d_A) from Π_Bell. |
| **Lemma 1, Proposition 7** – what replaces the Heisenberg–Weyl pair | Π_Bell is the twirl over a commuting pair (C, D). D is local; the block-cyclic shift C is a product of local operators only if d_A = d_B. The local unitary symmetries of the Bell basis are exactly the powers of D (up to phases). |
| **Section 6** – downstream audit | MWKB (10), (17), (21), Proposition 1/(20) and the evaluation (22)–(24) need correction for d_A < d_B. The 4×4 state (30), the 4×6 bound entangled states (38)–(39), the 3×4 search, the SSC noise threshold 0.1295 and Eq. (67) are reproduced independently. |

The numerical values in Table 1 / Figure 3 for the *maximal* negativity generated from product
states are lower bounds found by numerical optimization, not certified global maxima.

## Reproducing the 116 checks

Requirements: Python ≥ 3.9 with NumPy, SciPy and SymPy (the figure script additionally needs
Matplotlib).

```bash
pip install numpy scipy sympy matplotlib
python verify_unequal_bell_projection.py > verify_output.txt
```

The script prints one `[PASS]`/`[FAIL]` line per check and a summary; it exits with status 0
if and only if all 116 checks pass. Runtime is about two minutes on a laptop. It was last run
with Python 3.12, NumPy 1.26, SciPy 1.13 and SymPy 1.13.

What the checks cover:

- **A1** – orthonormality of the Bell basis; C and D commute and are diagonal in it; Π_Bell
  is the twirl over ⟨C, D⟩; the corrected Fourier representation.
- **A2** – MWKB (17), (21) and Proposition 1 fail for d_A < d_B and hold for d_A = d_B; the
  fidelity formula; the factorizations of Φ₁ and Π_Bell.
- **A3** – order of the group by exhaustive enumeration; fixed-point dimension gcd(d_A,d_B);
  the limit of Φ₁ⁿ.
- **B1–B2** – the 2×3 counterexample with exact rational spectrum; the eigenvalue
  −1/(4 d_A) in exact arithmetic for all 2 ≤ d_A < d_B ≤ 9 (d_A ≤ 7); controls for equal
  dimensions.
- **B3** – numerical optimization of the negativity over product states (seeded restarts).
- **C1–C2** – MWKB (22)–(24), the bound entangled states, the dichotomous searches, the SSC
  threshold and Eq. (67).
- **D** – local symmetries of the Bell basis and the block dephasing.

To regenerate the figures and the PDF:

```bash
python make_figures.py
pdflatex unequal_dimension_bell_projection_audit.tex   # run three times
```
